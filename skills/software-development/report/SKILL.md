# Report — Generate Work Summary

Produce a concise, structured report when work completes.

## Structure

```
## What Was Done
- [list completed items, each 1 line]

## Key Decisions
- [decision] — [why] — [impact]

## Files Changed
- [file]: [what changed]

## Next Steps
- [actionable items]
```

## Rules

1. **Headline first** — one sentence summary before details
2. **Decisions with rationale** — not just what, but why
3. **Actionable next steps** — concrete, not vague
4. **No filler** — every line adds value
5. **Keep under 500 words** for typical reports
