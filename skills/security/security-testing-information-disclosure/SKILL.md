# Information Disclosure Verification

Check errors, debug routes, source maps, backups, logs, exports, metadata, directory listings, generated documents, and unauthenticated APIs. Establish who should be able to access the data.

Version strings and public metadata are not automatically findings. Classify sensitivity, exploit usefulness, freshness, and whether access crosses a user, tenant, environment, or network boundary.

Confirm with the minimum sample needed to establish exposure. Redact secrets and personal data in reports, preserve the source location or exchange id, and state the affected population.
